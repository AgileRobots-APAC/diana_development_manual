# 网络配置

网络连接是所有 SDK、FCI 和 ROS 2 接入的前置步骤。开始编写程序前，请先参考机械臂使用手册完成机械臂本体、控制柜和示教器的连接，并确认机械臂已经成功上电。

## 控制 PC 连接控制柜

1. 使用控制 PC 的有线网口连接机械臂控制柜的 **A 网口**。
2. 默认情况下，机械臂控制柜 A 网口 IP 为 `192.168.10.75`；连接网口后，可在示教器的网络信息页面查看实际 IP。
3. 将控制 PC 的有线网口配置为静态 IP，并确保它与机械臂处于同一网段。例如：

   ```text
   机械臂控制柜 A 网口：192.168.10.75
   控制 PC：192.168.10.100
   子网掩码：255.255.255.0
   ```

4. 在开始接入前确认连通：

   ```bash
   ping 192.168.10.75
   ```

如设备随机附带网线，建议优先使用；自行准备时建议使用六类或六类以上网线。网络连通后，再进入所用接入方式（SDK、FCI 或 ROS 2）的开发准备和连接初始化流程。

## 端口职责与连接边界

| 端口 / 接口 | 用途 |
|---|---|
| A 网口 | 控制 PC、软示教器与 SDK API 通信 |
| D 网口 | TCP/IP 或 Modbus-TCP 等工业通信；不能替代 API 连接口 |
| B、C 网口 | 预留；当前不要作为 API 连接口使用 |
| RS232/485 | 可用于其他设备通信；SDK API 控制仍须使用以太网 |

## FCI 与 ROS 2 的网络要求

FCI 示例和 ROS 2 的启动参数 `robot_ip` 使用的是同一个控制柜地址，默认是 `192.168.10.75`，连接前同样要在示教器上确认实际地址。

FCI 与 ROS 2 是实时控制，对链路稳定性的要求比普通 SDK 调用更高：

- 控制 PC 与控制柜优先使用直连或确定性的网络环境；经过交换机、非直连、网线或 IP 配置不当，都是 FCI 连接和实时控制出问题的常见原因。
- 必须使用交换机时，应使用机器人专用的低延迟链路，不要在同一条链路上传输视频、下载文件或大规模日志。
- 内核实时性、网卡与链路检查的步骤，见 FCI 章节的“实时网络与系统配置”。

连接失败时，先确认线缆接在 A 网口，再检查控制 PC 的有线网卡是否为同一子网、是否能 `ping` 通控制柜，以及是否有其他程序正在占用或反复重连该机械臂。

```{note}
IP 地址和端口能力会随控制器配置变化。现场设备铭牌、示教器网络设置及对应控制柜手册优先于本页示例地址。
```
