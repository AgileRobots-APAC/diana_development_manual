# 06 I/O

该示例默认只读控制器板卡 `board` 的 `di0`、`do0`、`ai0`、`ao0` 和总线电参；显式参数才会写输出。

```bash
./build/bin/06_io --model diana7 --ip 192.168.10.75
./build/bin/06_io --model thor12 --ip 192.168.10.75 --set-do=1
./build/bin/06_io --model thor12 --ip 192.168.10.75 --set-ao=2:0.0
```

| API | 用途 |
|---|---|
| `readDI` / `readDO` / `writeDO` | 读取数字量输入/输出，显式参数下写数字输出 |
| `readAI` / `readAO` / `writeAO` | 读取模拟量输入/输出，显式参数下写模拟输出 |
| `readBusCurrent` / `readBusVoltage` | 读取总线电流和电压 |

## Example 调用流程

连接和轴数校验 → 读取并输出 I/O 与总线数据 → 检查可选写入参数 → 写入后输出返回值 → 释放服务。

### 关键源码片段

```cpp
int di = 0, ai_mode = 0;
double ai = 0.0;

if (readDI("board", "di0", di, ip) == 0)
    std::cout << "board/di0 = " << di << "\n";
if (readAI("board", "ai0", ai_mode, ai, ip) == 0)
    std::cout << "mode=" << ai_mode << ", value=" << ai << "\n";

const int do_ret = writeDO("board", "do0", value, ip);
const int ao_ret = writeAO("board", "ao0", mode, output, ip);
// V3.3：mode=1 时 output 范围为 4–20；mode=2 时范围为 0–10。
```

```{warning}
写 I/O 前确认示教器 AO 配置、端子接线、外部设备状态和允许输出范围。
```

## 逐项 API 用法与调用案例

### `readDI` / `readDO` / `writeDO`

````{container} api-example-block

| 函数 | 原型 | 返回值 |
| --- | --- | --- |
| `readDI` | `int readDI(const char *groupName, const char *IOName, int &value, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |
| `readDO` | `int readDO(const char *groupName, const char *IOName, int &value, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |
| `writeDO` | `int writeDO(const char *groupName, const char *IOName, int value, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |

| 参数 | 方向/类型 | 含义 |
| --- | --- | --- |
| `groupName` | 输入，`const char*` | I/O 分组名，例如控制器板卡 `board`。 |
| `IOName` | 输入，`const char*` | I/O 名称，例如 `di0`、`do0`；是否存在由控制器配置决定。 |
| `value` | 读接口为输出引用，写接口为输入 `int` | 数字量值，通常 `0` 表示低电平/关闭，`1` 表示高电平/打开，最终语义取决于现场接线和外设逻辑。 |
| `strIpAddress` | 输入，`const char*`，默认 `""` | 机械臂 IP；为空时仅适合单臂连接场景。 |

`readDI(group_name, name, value, ip)` 与 `readDO(group_name, name, value, ip)` 读取一个数字量；`writeDO(group_name, name, value, ip)` 写数字输出。`board` 是分组名，`di0`、`do0` 是信号名，是否存在由控制器配置决定。

本例仅在显式 `--set-do` 时调用 `writeDO`。写入前应确认端子、电平、外部供电、PNP/NPN 类型和外设动作逻辑，不要把测试输出接到未评审的执行器。

```{rubric} 调用案例
```

```cpp
int value = 0;
int ret = readDI("board", "di0", value, "192.168.10.75");
if (ret == 0) printf("di0: %d\n", value);

ret = writeDO("board", "do0", value, "192.168.10.75");
if (ret < 0) printf("writeDO failed!\n");
```


````

### `readAI` / `readAO` / `writeAO`

````{container} api-example-block

| 函数 | 原型 | 返回值 |
| --- | --- | --- |
| `readAI` | `int readAI(const char *groupName, const char *IOName, int &mode, double &value, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |
| `readAO` | `int readAO(const char *groupName, const char *IOName, int &mode, double &value, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |
| `writeAO` | `int writeAO(const char *groupName, const char *IOName, int mode, double value, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |

| 参数 | 方向/类型 | 含义 |
| --- | --- | --- |
| `groupName` | 输入，`const char*` | I/O 分组名，例如 `board`。 |
| `IOName` | 输入，`const char*` | 模拟量名称，例如 `ai0`、`ao0`。 |
| `mode` | 读接口为输出引用，写接口为输入 `int` | 模拟量模式；手册规定 `1` 为电流模式 `4-20 mA`，`2` 为电压模式 `0-10 V`。 |
| `value` | 读接口为输出引用，写接口为输入 `double` | 模拟量数值；单位和合法范围由 `mode` 决定。 |
| `strIpAddress` | 输入，`const char*`，默认 `""` | 机械臂 IP；为空时仅适合单臂连接场景。 |

`readAI(group_name, name, mode, value, ip)` 与 `readAO(group_name, name, mode, value, ip)` 读取模拟量并额外返回模拟量模式；`writeAO(group_name, name, mode, value, ip)` 按模拟量模式写输出。

手册规定 `mode=1` 为电流模式（4–20），`mode=2` 为电压模式（0–10）；超出范围会失败。因此示例的电压零输出写法为 `--set-ao=2:0.0`，但是否安全仍取决于外设逻辑。

```{rubric} 调用案例
```

```cpp
int mode = 2;
double value = 0.0;
readAI("board", "ai0", mode, value, "192.168.10.75");
readAO("board", "ao0", mode, value, "192.168.10.75");

// 1: 4–20 mA；2: 0–10 V
ret = writeAO("board", "ao0", mode, value, "192.168.10.75");
if (ret < 0) printf("writeAO failed!\n");
```


````

### `readBusCurrent` / `readBusVoltage`

````{container} api-example-block

| 函数 | 原型 | 返回值 |
| --- | --- | --- |
| `readBusCurrent` | `int readBusCurrent(double &current, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |
| `readBusVoltage` | `int readBusVoltage(double &voltage, const char *strIpAddress = "")` | `0` 表示成功，`-1` 表示失败。 |

| 参数 | 方向/类型 | 含义 |
| --- | --- | --- |
| `current` | 输出引用，`double&` | 控制器总线电流读数。 |
| `voltage` | 输出引用，`double&` | 控制器总线电压读数。 |
| `strIpAddress` | 输入，`const char*`，默认 `""` | 机械臂 IP；为空时仅适合单臂连接场景。 |

`readBusCurrent(current, ip)` 与 `readBusVoltage(voltage, ip)` 读取控制器总线电参，适合诊断留档，不是外设电源额定值的替代。API 返回成功也不表示现场接线或负载状态安全。

```{rubric} 调用案例
```

```cpp
double current = 0.0;
double voltage = 0.0;
readBusCurrent(current, "192.168.10.75");
readBusVoltage(voltage, "192.168.10.75");
```
````
