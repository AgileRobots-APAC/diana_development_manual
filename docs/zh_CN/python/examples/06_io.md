# 06 I/O

本示例演示 DI / DO / AI / AO 和总线电参读取。默认只读；写输出需要显式提供对应参数。

```bash
python3 examples/06_io/main.py --model diana7 --ip 192.168.10.75
python3 examples/06_io/main.py --model diana7 --ip 192.168.10.75 --set-do=1
python3 examples/06_io/main.py --model diana7 --ip 192.168.10.75 --set-ao=0:0.0
```

| API | 用途 |
|---|---|
| `readDI` / `readDO` / `writeDO` | 数字输入、数字输出读取与写入 |
| `readAI` / `readAO` / `writeAO` | 模拟输入、模拟输出读取与写入 |
| `readBusCurrent` / `readBusVoltage` | 读取总线电流与电压 |

## Example 调用流程

初始化连接 → 校验型号与轴数 → 读取 `board/di0`、`board/do0`、`board/ai0`、`board/ao0` → 读取总线电流和电压 → 如果传入 `--set-do` 或 `--set-ao`，执行对应写入 → 释放资源。

### 关键源码片段

```python
ret, value = api.readDI("board", "di0", args.ip)
ret, value = api.readDO("board", "do0", args.ip)
ret, mode, value = api.readAI("board", "ai0", args.ip)
ret, mode, value = api.readAO("board", "ao0", args.ip)

ret, value = api.readBusCurrent(args.ip)
ret, value = api.readBusVoltage(args.ip)

if args.set_do is not None:
    api.writeDO("board", "do0", args.set_do, args.ip)
if args.set_ao:
    mode_text, value_text = args.set_ao.split(":", 1)
    api.writeAO("board", "ao0", int(mode_text), float(value_text), args.ip)
```

## 逐项 API 用法与调用案例

```{attention}
`DianaApi.py` 中 I/O 函数的参数名与 Python API 手册不完全一致，也不总能反映通道类型：例如 `readDO`、`writeDO`、`writeAO` 的信号名参数都叫 `di_name`，`readAO` 叫 `do_name`，而手册写作 `do_name`、`ao_name`、`name`。请像本例一样**按位置传参**，不要使用 `do_name=`、`ao_name=` 等关键字形式，否则会抛出 `TypeError`。
```

### `readDI` / `readDO` / `writeDO`

````{container} api-example-block

| 函数 | 原型 | 返回值 |
|---|---|---|
| `readDI` | `readDI(group_name, di_name, ipAddress='')` | 返回 (ret, value)，ret == 0 表示成功 |
| `readDO` | `readDO(group_name, di_name, ipAddress='')` | 返回 (ret, value)，ret == 0 表示成功 |
| `writeDO` | `writeDO(group_name, di_name, value, ipAddress='')` | 成功返回 True，失败返回 False |

| 参数 | 方向/类型 | 含义 |
| --- | --- | --- |
| `group_name` | 输入，`str` | I/O 分组名，例如 `'board'`、`'plc'`、`'endpoint'`；三个函数共用。 |
| `di_name` | 输入，`str` | 信号名；`readDI` 中为数字输入名（如 `'di0'`），`readDO` / `writeDO` 中为数字输出名（如 `'do0'`）。wrapper 在三个函数中都把该参数命名为 `di_name`；通道是否存在由控制器配置决定。 |
| `value` | 输入，`int` | 仅 `writeDO` 使用：写入的数字输出值，通常 `0` 表示低电平/关闭，`1` 表示高电平/打开，最终语义取决于现场接线和外设逻辑。读取结果不通过参数传出，而是作为返回元组中的 `ctypes.c_int` 返回。 |
| `ipAddress` | 输入，`str`，默认 `''` | 机械臂 IP；为空时仅适合单臂连接场景。三个函数共用。 |

Python I/O 读取接口通常返回 `(ret, value)`，其中 `ret == 0` 表示读取成功，`value.value` 是 `ctypes` 输出值。示例默认只读，只有传入 `--set-do` 才写 `board/do0`；`--set-do` 只接受 `0` 或 `1`。

```python
ret, value = api.readDO("board", "do0", ip)
if ret == 0:
    print(value.value)

api.writeDO("board", "do0", 1, ip)
```

````

```{warning}
`--set-do` 和 `--set-ao` 会真实修改控制器输出。写入前确认通道映射、外接设备逻辑、电压/电流模式和允许值；不要把示例中的 `board/do0`、`board/ao0` 直接视为现场安全通道。
```

### `readAI` / `readAO` / `writeAO`

````{container} api-example-block

| 函数 | 原型 | 返回值 |
|---|---|---|
| `readAI` | `readAI(group_name, di_name, ipAddress='')` | 返回 (ret, mode, value)，ret == 0 表示成功 |
| `readAO` | `readAO(group_name, do_name, ipAddress='')` | 返回 (ret, mode, value)，ret == 0 表示成功 |
| `writeAO` | `writeAO(group_name, di_name, mode, value, ipAddress='')` | 成功返回 True，失败返回 False |

| 参数 | 方向/类型 | 含义 |
| --- | --- | --- |
| `group_name` | 输入，`str` | I/O 分组名，例如 `'board'`、`'plc'`、`'endpoint'`；三个函数共用。 |
| `di_name` | 输入，`str` | `readAI` 与 `writeAO` 使用的信号名：`readAI` 中为模拟输入名（如 `'ai0'`），`writeAO` 中为模拟输出名（如 `'ao0'`），wrapper 沿用了 `di_name` 这一参数名。 |
| `do_name` | 输入，`str` | `readAO` 使用的模拟输出名，例如 `'ao0'`。 |
| `mode` | 输入，`int` | 仅 `writeAO` 使用：模拟输出模式，`1` 为电流，`2` 为电压。`readAI` / `readAO` 读到的模式以返回元组中的 `ctypes.c_int` 给出，取值含义相同。 |
| `value` | 输入，`float` | 仅 `writeAO` 使用：模拟输出值，单位和合法范围由 `mode` 及现场设备决定。读取值以返回元组中的 `ctypes.c_double` 给出。 |
| `ipAddress` | 输入，`str`，默认 `''` | 机械臂 IP；为空时仅适合单臂连接场景。三个函数共用。 |

模拟量读取返回 `(ret, mode, value)`；先检查 `ret == 0`，再读取 `mode.value` 与 `value.value`。写 AO 时，示例使用 `--set-ao=<mode>:<value>` 解析模式和值。

```python
ret, mode, value = api.readAO("board", "ao0", ip)
if ret == 0:
    print(mode.value, value.value)

api.writeAO("board", "ao0", 0, 0.0, ip)
```

````

### `readBusCurrent` / `readBusVoltage`

````{container} api-example-block

| 函数 | 原型 | 返回值 |
|---|---|---|
| `readBusCurrent` | `readBusCurrent(ipAddress='')` | 返回 (ret, value)，ret == 0 表示成功 |
| `readBusVoltage` | `readBusVoltage(ipAddress='')` | 返回 (ret, value)，ret == 0 表示成功 |

| 参数 | 方向/类型 | 含义 |
| --- | --- | --- |
| `ipAddress` | 输入，`str`，默认 `''` | 机械臂 IP；为空时仅适合单臂连接场景。`readBusCurrent`、`readBusVoltage` 共用；总线电流/电压读数以返回元组中的 `ctypes.c_double` 给出。 |

总线电参读取同样返回 `(ret, value)`。这些值可用于运行状态观察，但不能替代控制柜或安全系统的电气诊断。

```python
ret, current = api.readBusCurrent(ip)
ret, voltage = api.readBusVoltage(ip)
```
````
