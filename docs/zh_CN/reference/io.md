# I/O 与映射

本页只说明各 SDK 共用的 I/O 与映射概念。具体函数名、参数类型、模块名或 topic / service 名称，应在对应 SDK 页面或独立接口参考中查看。

| 类别 | 说明 | 常见用途 |
|---|---|---|
| 数字输入 DI | 读取开关量输入状态 | 夹具到位、传感器触发、安全互锁信号 |
| 数字输出 DO | 控制开关量输出 | 控制夹具、电磁阀、指示灯 |
| 模拟输入 AI | 读取连续量输入 | 压力、位移、力传感器等外部信号 |
| 模拟输出 AO | 输出连续量控制信号 | 给外部设备设定速度、压力或比例阀参数 |
| 地址映射 | 将控制器变量、I/O 或外部数据建立映射关系 | 与工艺设备、PLC 或上位机交换数据 |
| 映射锁定 | 控制映射地址是否允许修改 | 防止运行中被误改，提升流程稳定性 |

使用 I/O 前，应同时确认控制箱端子定义、电气规格、PNP / NPN 接线方式、外部供电和现场安全逻辑。

## 接线与量程确认

对支持该配置的控制箱，数字量 I/O 的 PNP / NPN 类型由 COM 端接线决定；模拟量 I/O 还可能需要在电压量程和电流量程之间切换。软件读写前请完成以下确认：

1. 按控制箱用户手册确认端子号、COM 接法、输入/输出方向和外部供电；
2. 以万用表或安全的离线信号源验证电平与量程，再接入夹具或工艺设备；
3. 将 I/O 异常、夹具未到位和安全互锁纳入应用状态机，不能只依赖一次读取结果；
4. 对运行中不应修改的地址映射，按控制器能力启用锁定或在应用层禁止修改。

```{note}
控制箱端子定义、电气参数、PNP/NPN 接线等硬件资料不属于这本 V3.3.0 API 手册的主体内容，正式站点应从控制箱用户手册单独引入，避免把 API 语义和硬件接线混在一页。
```
