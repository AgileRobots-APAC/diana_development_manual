# 安全边界

```{danger}
API 网页不能替代机器人安全手册、风险评估、现场急停 / 防护配置和功能安全说明。
```

本页说明 API 文档能够覆盖的安全软件边界；现场操作前仍必须遵循对应型号的用户手册和安全规程。

## 首次接入与重新部署检查

在首次运行程序、变更工具/负载或重新部署后，至少确认：

- 机械臂底座、工具和线缆已固定，工作空间内无人员和障碍物；
- 急停、使能装置、外部保护停止及现场互锁已按安全规程验证；
- 工具负载、重心、TCP 和坐标系已按实际工装配置；
- 控制 PC 网络连接正确，当前控制器无待处理错误；
- 首次运动采用保守的速度、加速度和范围，操作人员可立即触及急停。

```{note}
这是软件接入前的最低检查项，不是完整的风险评估或验收清单。安装强度、停机距离、保护装置和环境要求以对应型号的用户手册及现场安全方案为准。
```

V3.3.0 API 手册中可以直接查到的安全相关软件入口包括：

- 碰撞检测与阈值
- 救援模式
- 关节 / 笛卡尔运动限制
- 上电 / 下电接口
- 错误码中的急停、STO、保护停止和安全工作空间错误

发生安全相关停止或错误时，先保存错误码、机器人状态和最近一次指令，再查看[错误码](error_codes.md)和[故障排查](troubleshooting.md)。不要仅靠重复清错或重新下发运动指令恢复现场。
