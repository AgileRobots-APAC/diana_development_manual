# 单位与数据约定

| 物理量 | 单位 |
|---|---|
| 力 | N |
| 扭矩 | Nm |
| 电流 | A |
| 长度 | m |
| 线速度 | m/s |
| 线加速度 | m/s² |
| 角度 | rad |
| 角速度 | rad/s |
| 角加速度 | rad/s² |
| 时间 | s |

除非函数页面明确说明，否则旋转量按轴角理解。不同接口的数组顺序、位姿表达和坐标系含义仍应以其函数说明为准。

## 关节数量

文档统一使用 `JOINT_NUM`：

- Diana：`JOINT_NUM = 7`
- Thor：`JOINT_NUM = 6`

```{important}
示例、数组长度和运动学说明应尽量使用 `JOINT_NUM`，避免把 7 轴硬编码到所有型号。
```
