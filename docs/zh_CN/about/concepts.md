## 选择接入方式

同一套控制概念可以通过不同的接入方式使用。先选定接入方式，再进入对应的编程指南：

| 接入方式 | 适合的任务 | 运行方式 | 主要前提 |
|---|---|---|---|
| C++ / Python SDK | 离散运动指令、I/O、路径、工具坐标系和控制器功能调用 | 调用控制器提供的接口，由控制器生成并执行运动 | 控制 PC 与控制柜网络连通 |
| FCI | 实时闭环、模型计算和力矩控制 | 应用在实时回调中，于每个控制周期连续提供目标或力矩 | 实时控制链路已验证，回调不做阻塞 I/O，协作模式 |
| ROS 2 | 接入 ROS 2 生态：`ros2_control` 控制器、MoveIt 规划和 Gazebo 仿真 | 通过 `diana_hardware` 硬件接口，控制器在控制周期内读写接口，每个周期只按一种命令模式运行 | 受支持的 Ubuntu 与 ROS 2 发行版、`libfranka 0.18.2`、实时权限，实机还需协作模式 |

FCI 回调和 ROS 2 控制器都运行在实时控制周期内，“控制模型与模式选择”中关于实时类控制的原则同样适用。

函数名、结构体字段和每个参数的合法范围不在本节重复，请以各接入方式的编程指南和独立维护的 API Reference 为准。
