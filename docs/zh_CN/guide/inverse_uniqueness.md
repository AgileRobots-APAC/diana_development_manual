# 逆解选择与构型连续性

本页主要面向 Diana 等冗余自由度机械臂。它们可能出现“同一 TCP 位姿，对应多组关节构型”的情况；为了让机器人沿着预期的关节角运动，需要在轨迹设计时确保逆解唯一。

```{figure} ../../_static/diagrams/redundant_ik.png
:alt: 同一 TCP 位姿对应多个冗余构型示意图
:width: 100%

同一 TCP 位姿可能对应多个不同关节构型。实际规划时应结合参考点的关节角、关节限位、奇异性、碰撞风险和路径连续性选择最合适的一组逆解。
```

## 情况一：已知某个路点的关节角

例如已知 A 点关节角和 B 点位姿。

| 步骤 | 推荐做法 | 目的 |
|---|---|---|
| 回到 A 点 | 直接使用 A 点已知关节角作为目标 | 回到确定构型 |
| 从 A 点去 B 点 | 使用目标位姿生成下一段运动 | 让系统在已知构型附近求解 |
| 做往复运动 | 持续用 A 点已知关节角回到 A 点 | 每次都回到同一组关节角 |

## 情况二：所有路点只有位姿，没有关节角

| 步骤 | 推荐做法 | 目的 |
|---|---|---|
| 准备参考点 | 在每个目标位姿附近示教一个参考点 | 为逆解提供参考 |
| 记录参考关节角 | 记录各参考点的关节角 | 作为求逆解时的参考 |
| 求目标点逆解 | 用带参考关节角的逆解函数（`inverse_ext`），求与参考关节角欧氏距离最近的逆解 | 让逆解落在参考点附近 |
| 执行运动 | 以求得的关节角作为目标运动（`moveJToTarget` 或 `moveLToTarget`） | 按已经求得的关节角运动 |

## 情况三：实时笛卡尔控制（FCI 与 ROS 2）

FCI 回调或 ROS 2 控制器在每个控制周期下发笛卡尔位姿或速度，逆解由控制器在内部完成，应用只能通过位姿的连续性和肘部参数来约束构型。

| 步骤 | 推荐做法 | 目的 |
|---|---|---|
| 读取起点 | 先读取当前位姿和当前肘部值，把它们作为第一个周期的目标 | 第一拍与当前状态一致，不发生突变 |
| 保持构型 | 每个周期都随位姿一起下发肘部参数，只在需要时改动它 | 在 7 轴冗余自由度上固定构型 |
| 保持连续 | 相邻周期的位姿和肘部值只做小幅变化 | 避免相对当前状态突变 |

FCI 示例 `generate_elbow_motion` 和 ROS 2 的 `cartesian_elbow_example_controller` 都是这样做的：先读取初始位姿和肘部值，再逐步改变肘部的关节 3，同时保持末端位姿不变。

## 情况四：ROS 2 中由 MoveIt 求解逆解

在 ROS 2 中，`joint_impedance_with_ik_example_controller` 这类需要逆解的控制器通过 MoveIt 的 `compute_ik` 服务求解，求解器由 `diana_moveit_config` 的 `kinematics.yaml` 指定（默认是 `lma_kinematics_plugin/LMAKinematicsPlugin`）。求解器对一个目标位姿给出的是其中一组解，不保证与示教时的构型一致，因此仍应遵循下面的设计原则：保存关节角，并对关键路点保留参考点的关节角。

## 设计原则

| 原则 | 说明 |
|---|---|
| 能保存关节角就不要只保存位姿 | 关节角天然包含构型信息 |
| 需要笛卡尔目标时，配套保存参考点的关节角 | 逆解函数以它为参考，求出距离最近的解 |
| 往复运动中，至少有一个点用关节角作目标 | 回到该点时用关节角而不是位姿，每次都回到同一组关节角，不必再求逆解 |

具体 SDK 中如何传入参考关节角、如何枚举或筛选候选解，请查看对应 SDK 的编程指南或独立接口参考。
