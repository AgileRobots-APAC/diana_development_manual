# 坐标、位姿与运动学

本页只说明跨 SDK 共用的运动学概念。具体函数名、消息类型或绑定名称，应在对应 SDK 页面中查看。

## 正逆运动学

| 需求 | 概念 | 说明 |
|---|---|---|
| 已有关节角，求末端位姿 | 正运动学 | 用机器人模型计算 TCP 位姿 |
| 已有末端位姿，求关节角 | 逆运动学 | 可能存在多组候选解 |
| 已有末端位姿和参考关节角 | 带参考的逆解 | 以参考关节角为参考，求出与其距离最近的逆解 |
| 需要查看多个候选解 | 多解枚举 / 解筛选 | 根据关节限位、路径连续性和工艺约束选择 |

冗余自由度机械臂的同一末端位姿可能对应多组关节解。对 7 轴机械臂执行笛卡尔空间运动前，请同时阅读 [逆解选择与构型连续性](inverse_uniqueness.md)。

## 姿态与坐标变换

| 需求 | 概念 |
|---|---|
| 在不同姿态表达之间转换 | RPY、轴角、四元数等姿态表达转换 |
| 在矩阵和位姿之间转换 | 齐次矩阵与位姿表示转换 |
| 把位姿从一个坐标系换到另一个坐标系 | 坐标变换 / 位姿变换 |
| 描述工具或工件相对关系 | TCP、法兰、基坐标系、工件坐标系 |

## 模型参数与雅可比

| 需求 | 概念 |
|---|---|
| 描述机器人连杆几何关系 | DH 参数或等价运动学模型 |
| 标定或修正模型 | DH 标定 / 模型参数修正 |
| 建立关节速度与 TCP 速度关系 | 雅可比矩阵 |
| 判断奇异或接近奇异 | 雅可比退化与条件数分析 |

## FCI 与 ROS 2 中的坐标系与冗余参数

- **冗余参数**：FCI 和 ROS 2 的笛卡尔位姿、笛卡尔速度命令都可以附带肘部参数，用来在 7 轴机械臂的多组关节构型中固定想要的那一组，思路与[逆解选择与构型连续性](inverse_uniqueness.md)一致。肘部参数是两个数：第一个是关节 3 的期望位置（rad），机械臂在末端位姿不变时可以靠转动关节 3 改变肘部的位置；第二个是关节 4 的翻转方向，用来区分肘部朝哪一侧。在 ROS 2 中它写作 `[joint_3_position, joint_4_sign]`，对应 `elbow_command` 接口。
- **末端坐标系（ROS 2）**：名义末端坐标系 NE、末端执行器坐标系 EE 和刚度坐标系 K 依次相连。服务 `set_tcp_frame` 设置 NE 到 EE 的变换 NE_T_EE，`set_stiffness_frame` 设置 EE 到 K 的变换 EE_T_K；笛卡尔刚度在 K 的各轴方向上生效。
