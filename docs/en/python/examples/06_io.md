# 06 I/O

This example demonstrates DI / DO / AI / AO and bus electrical-value reads. It is read-only by default; writes require explicit arguments.

```bash
python3 examples/06_io/main.py --model diana7 --ip 192.168.10.75
python3 examples/06_io/main.py --model diana7 --ip 192.168.10.75 --set-do=1
python3 examples/06_io/main.py --model diana7 --ip 192.168.10.75 --set-ao=0:0.0
```

| API | Purpose |
|---|---|
| `readDI` / `readDO` / `writeDO` | Digital input/output |
| `readAI` / `readAO` / `writeAO` | Analog input/output |
| `readBusCurrent` / `readBusVoltage` | Bus current and voltage |

## Example Call Flow

Initialize the connection → validate the model and axis count → read `board/di0`, `board/do0`, `board/ai0`, and `board/ao0` → read bus current and voltage → if `--set-do` or `--set-ao` is supplied, perform the corresponding write → release resources.

### Key Source Snippet

```python
ret, value = api.readDI("board", "di0", args.ip)
ret, value = api.readDO("board", "do0", args.ip)
ret, mode, value = api.readAI("board", "ai0", args.ip)
ret, mode, value = api.readAO("board", "ao0", args.ip)

ret, value = api.readBusCurrent(args.ip)
ret, value = api.readBusVoltage(args.ip)

if args.set_do is not None:
    api.writeDO("board", "do0", args.set_do, args.ip)
if args.set_ao:
    mode_text, value_text = args.set_ao.split(":", 1)
    api.writeAO("board", "ao0", int(mode_text), float(value_text), args.ip)
```

## API Usage and Call Examples

```{attention}
The I/O parameter names in `DianaApi.py` do not fully match the Python API manual and do not always reflect the channel type: for example, the signal-name parameter of `readDO`, `writeDO`, and `writeAO` is called `di_name`, and that of `readAO` is `do_name`, while the manual uses `do_name`, `ao_name`, and `name`. Pass arguments **positionally**, as this example does; keyword forms such as `do_name=` or `ao_name=` raise `TypeError`.
```

### `readDI` / `readDO` / `writeDO`

````{container} api-example-block

| Function | Prototype | Return Value |
|---|---|---|
| `readDI` | `readDI(group_name, di_name, ipAddress='')` | Returns `(ret, value)`; `ret == 0` indicates success |
| `readDO` | `readDO(group_name, di_name, ipAddress='')` | Returns `(ret, value)`; `ret == 0` indicates success |
| `writeDO` | `writeDO(group_name, di_name, value, ipAddress='')` | `True` on success; otherwise `False` |

| Parameter | Direction / Type | Meaning |
| --- | --- | --- |
| `group_name` | In, `str` | I/O group name, for example `'board'`, `'plc'`, or `'endpoint'`. Shared by all three functions. |
| `di_name` | In, `str` | Signal name: a digital input name (such as `'di0'`) for `readDI`, a digital output name (such as `'do0'`) for `readDO` / `writeDO`. The wrapper names this parameter `di_name` in all three functions; channel availability depends on controller configuration. |
| `value` | In, `int` | `writeDO` only: digital output value to write. Typically `0` means low/off and `1` means high/on, but the final meaning depends on wiring and external device logic. Read values are not passed out through parameters; they come back as a `ctypes.c_int` in the returned tuple. |
| `ipAddress` | In, `str`, default `''` | Robot IP. An empty value is only appropriate for single-arm connections. Shared by all three functions. |

Python I/O read calls usually return `(ret, value)`, where `ret == 0` indicates a successful read and `value.value` holds the `ctypes` output value. The example is read-only by default and writes `board/do0` only when `--set-do` is supplied; `--set-do` accepts `0` or `1`.

```python
ret, value = api.readDO("board", "do0", ip)
if ret == 0:
    print(value.value)

api.writeDO("board", "do0", 1, ip)
```

````

```{warning}
`--set-do` and `--set-ao` change real controller outputs. Before writing, verify channel mapping, attached-device logic, voltage/current mode, and allowed values. Do not treat the example channels `board/do0` and `board/ao0` as safety channels on site.
```

### `readAI` / `readAO` / `writeAO`

````{container} api-example-block

| Function | Prototype | Return Value |
|---|---|---|
| `readAI` | `readAI(group_name, di_name, ipAddress='')` | Returns `(ret, mode, value)`; `ret == 0` indicates success |
| `readAO` | `readAO(group_name, do_name, ipAddress='')` | Returns `(ret, mode, value)`; `ret == 0` indicates success |
| `writeAO` | `writeAO(group_name, di_name, mode, value, ipAddress='')` | `True` on success; otherwise `False` |

| Parameter | Direction / Type | Meaning |
| --- | --- | --- |
| `group_name` | In, `str` | I/O group name, for example `'board'`, `'plc'`, or `'endpoint'`. Shared by all three functions. |
| `di_name` | In, `str` | Signal name used by `readAI` and `writeAO`: an analog input name (such as `'ai0'`) for `readAI`, an analog output name (such as `'ao0'`) for `writeAO`. The wrapper keeps the parameter name `di_name` in both. |
| `do_name` | In, `str` | Analog output name used by `readAO`, for example `'ao0'`. |
| `mode` | In, `int` | `writeAO` only: analog output mode, `1` for current and `2` for voltage. `readAI` / `readAO` return the mode as a `ctypes.c_int` in the result tuple with the same meaning. |
| `value` | In, `float` | `writeAO` only: analog output value. Its unit and valid range depend on `mode` and the connected device. Read values come back as a `ctypes.c_double` in the result tuple. |
| `ipAddress` | In, `str`, default `''` | Robot IP. An empty value is only appropriate for single-arm connections. Shared by all three functions. |

Analog reads return `(ret, mode, value)`; check `ret == 0`, then use `mode.value` and `value.value`. To write AO, the example parses the mode and value from `--set-ao=<mode>:<value>`.

```python
ret, mode, value = api.readAO("board", "ao0", ip)
if ret == 0:
    print(mode.value, value.value)

api.writeAO("board", "ao0", 0, 0.0, ip)
```
````

### `readBusCurrent` / `readBusVoltage`

````{container} api-example-block

| Function | Prototype | Return Value |
|---|---|---|
| `readBusCurrent` | `readBusCurrent(ipAddress='')` | Returns `(ret, value)`; `ret == 0` indicates success |
| `readBusVoltage` | `readBusVoltage(ipAddress='')` | Returns `(ret, value)`; `ret == 0` indicates success |

| Parameter | Direction / Type | Meaning |
| --- | --- | --- |
| `ipAddress` | In, `str`, default `''` | Robot IP. An empty value is only appropriate for single-arm connections. Shared by `readBusCurrent` and `readBusVoltage`; the bus current/voltage reading comes back as a `ctypes.c_double` in the result tuple. |

Bus electrical reads also return `(ret, value)`. These values are useful for observing runtime status, but they are not a substitute for electrical diagnostics by the control cabinet or safety system.

```python
ret, current = api.readBusCurrent(ip)
ret, voltage = api.readBusVoltage(ip)
```
````
